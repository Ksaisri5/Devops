# DevOps Lab

Lab experiments covering Git, Jenkins, Docker, Kubernetes and Selenium.

| No. | Experiment |
|-----|------------|
| 1 | User Registration Form Using Flask and Docker |
| 2 | Important Git and GitHub Commands |
| 3 | Create a New Repo from Command Line, Create File, and Push |
| 4 | Jenkins Installation and Setup, Explore the Environment |
| 5 | Demonstrate Continuous Integration and Development Using Jenkins |
| 6 | Explore Docker Commands for Content Management |
| 7 | Develop a Simple Containerized Application Using Docker |
| 8 | Integrate Kubernetes and Docker |
| 9 | Automate Running Containerized App Using Kubernetes |
| 10 | Install and Explore Selenium for Automated Testing |
| 11 | Write JavaScript Program and Perform Testing Using Selenium |
| 12 | Develop Test Cases for Containerized Application Using Selenium |

Each `exp N` folder has a `commands.sh` with the steps to run, plus the source files for that experiment.
